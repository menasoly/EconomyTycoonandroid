# Game Design Document

## Core loop

1. Observe markets, finances and competitors.
2. Decide: build, produce, price, hire, finance, research, expand.
3. Run time at chosen speed.
4. Review outcomes with explanations; adjust.

Short loop (minutes): pricing, scheduling. Medium (sessions): new facility, product launch. Long: regional expansion, group structures, capital markets.

## Modes

| Mode | Description |
|---|---|
| Tutorial | Guided single-industry start with advisor prompts |
| Sandbox | Open world, adjustable economy parameters |
| Scenario | Authored start with objectives and constraints |
| Campaign | Chained scenarios with progression |
| Challenge | Time-boxed objectives with fixed seeds |

## Difficulty

Difficulty adjusts starting capital, AI aggression, event frequency and information visibility. It never changes the rules the player and AI share.

## Progression

Unlocks by milestones: industries, technologies, regions, corporate structures. Achievements and prestige are cosmetic or convenience; no unfair economic advantage in shared worlds.

## Player aids

Advisors summarizing alerts, automation policies (reorder, pricing rules), explainers on every key number.

## Feedback and fairness

Every failure shows the violated rule. Randomness is seeded, so challenge runs are reproducible.

## Failure and recovery

Bankruptcy is a possible outcome; scenarios offer restart from checkpoints. Autosaves allow rewinding to earlier checkpoints in sandbox.

## Accessibility of depth

Default simple controls with progressive disclosure of advanced controls. Automation can be turned on per area.
